# Campus Energy Seer

## 📌 Project Overview

Campus Energy Seer is a web-based energy monitoring and visualization application designed to help campuses understand and track their energy consumption.

The application provides an interactive dashboard where energy-related information can be presented through visual metrics and data visualizations, supporting better understanding of campus energy usage.

## 🎯 Objectives

- Monitor campus energy consumption
- Visualize energy usage through an interactive dashboard
- Track important energy-related metrics
- Identify energy consumption patterns
- Support data-driven energy management
- Provide a user-friendly interface for monitoring campus energy

## 🛠️ Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- shadcn/ui

## ✨ Key Features

- Interactive energy monitoring dashboard
- Energy consumption metrics
- Data visualization
- Responsive user interface
- Modern dashboard design
- Component-based React architecture
